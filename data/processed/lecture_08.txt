Concrete example using base Transformer as reference
●Use the base Transformer model presented by Vaswani et al. 2017:
○Transformer weights have dimensions 𝑑× 𝑘= 512 × 64
○So 512 × 64 = 32,768 trainable parameters
In LoRA with rank 𝑟= 8:
●𝐴 has dimensions 𝑟× 𝑘= 8 × 64 = 512 parameters
●𝐵 has dimensions 𝑑× 𝑟= 512 × 8 = 4,096 parameters
●86% reduction in parameters to train!
